# OmniPanel 1.0.9 test build

The reader information card now offers six saved layouts: large cover left, cover above information, information above cover, balanced side by side, information left with cover right, and a wide cover banner. The cover has no surrounding card background; only the information panel has a background. Long information can be scrolled.

The white-background launcher icon uses full-resolution traced vector paths. The reader-card failure was fixed in version 1.0.5 by correcting the page-counter interface call. On a Galaxy Tab S9 FE+, 1.0.5 displayed the card and successfully fetched credits for one comic via ComicVine. On the same tablet, all six layouts in 1.0.9 were selected successfully, the large-cover layout was visually checked, and the selection remained after the reader controls were reopened. Other devices and features have not been exhaustively tested.

OmniPanel is free and was developed through vibe coding with AI coding tools. It updates Apollon in place using the same app ID and signing certificate. ComicVine lookup requires your own API key and internet access; an automatic match is not guaranteed.
