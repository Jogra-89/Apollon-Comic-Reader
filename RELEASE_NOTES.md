# OmniPanel 1.0.16 test release

This update moves the information-layout choice to Settings, keeps covers uncropped, uses theme fonts and a translucent blurred information background, and reserves space for page thumbnails. Each of the six layouts remembers its own compact, standard or large thumbnail setting. A settings-group jump menu makes the long settings screen easier to navigate.

Creator portraits load from ComicVine for a matched issue when a matching person and image are available; the app uses placeholders otherwise. This requires the user's own ComicVine API key and internet access. Publisher logos are shown when already cached by the app.

All six layouts and all three thumbnail sizes were exercised on a Galaxy Tab S9 FE+ in version 1.0.16, and creator portraits loaded for one matched comic during testing. Device and feature combinations have not been exhaustively tested.

OmniPanel is free and was developed through vibe coding with AI coding tools. It updates earlier Apollon and OmniPanel builds in place with the same app ID and signing certificate.
