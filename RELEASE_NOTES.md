# OmniPanel 1.0.17 test release

- Fixed a crash when opening Reading settings from the reader.
- Moved creator portraits to the top of the reader information panel, ahead of the synopsis and credits. When creator credits, an issue match, or a ComicVine API key are missing, the panel now explains what is needed. The ComicVine match button is also easier to find.
- Creator portraits require a matched ComicVine issue, an API key, internet access, and available images; ambiguous or unavailable portraits remain placeholders.

On a Galaxy Tab S9 FE+, the reader settings opened twice, panel sensitivity and the six layout choices were reachable, and two creator portraits displayed for one matched comic. Other devices and combinations are not exhaustively tested.

OmniPanel is free and was developed through vibe coding with AI coding tools. This APK updates the earlier Apollon and OmniPanel builds in place.
